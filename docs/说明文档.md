## 项目简介

本项目是面向《血染钟楼·暗流涌动》的网页辅助推理工具。玩家在圆桌上录入身份声明、技能观察、夜间死亡、白天投票与临时假设，系统把这些信息转换为逻辑约束，用 Z3 求解器检查是否一致，并给出身份或阵营的可能、必然与不可能结论。工具区分已确认记录、玩家自述声明和用户假设，结论始终以当前启用的输入为条件，不使用大语言模型猜测答案，也不代替说书人。

当前范围是 5–15 人暗流涌动普通局。部分角色只能记录或只转换部分规则，尚未覆盖旅行者、其他剧本和完整胜负判定；冲突解释是规则组和输入级依据，不宣称是逐步证明或最小冲突。

## 功能说明

### 对局录入与圆桌

首次进入通过三步向导选择 5–15 人、本人座位和初始身份。身份保存为可撤销的 `reported` 声明，不等同于真实身份。圆桌按座位排列玩家，可在初始配置、夜晚和白天之间推进及回看；点击玩家可添加身份或阵营假设，录入技能目标与结果；夜间确认死亡，白天记录提名、投票和处决；推理区还可添加“某角色在该时点不在场”的全局假设。各类记录可停用，停用项不参与本次推理。

### 推理结果

点击“开始推理”后，网页发送当前完整对局快照。后台先做协议校验，再调用 Z3 模型：先判断全局是否一致，再按查询检查命题及其否定，得到 `possible`、`necessary`、`impossible`、`inconsistent` 或 `unknown`，并返回按玩家列出的身份候选。矛盾时返回涉及的输入与规则组，并逐条说明输入是已应用、部分应用、仅记录还是已停用。网络或协议错误与逻辑矛盾分开显示。

可选“概率估计模式”会额外估计初始身份概率：公开输入作为硬条件，其他启用输入按玩家分组，以 0.7 可信度采信并枚举组合；互相矛盾的组合会排除，而不是必然让整次估计失败。结果明确标注为带权抽样估计，不是精确概率；超时或预算不足返回 `unknown`，未采样到的角色不代表概率为零。该估计不改变本次逻辑结论。

### 使用方式

```sh
pip install -r requirements.txt
python main.py web --host 127.0.0.1 --port 8000
```

浏览器访问 `http://127.0.0.1:8000/`，按以下流程操作：

1. 新建对局，选择人数、本人座位和初始身份。
2. 推进昼夜，录入死亡、投票、技能观察或假设；也可用“新增假设”添加全局条件。
3. 点击“开始推理”，查看一致性、身份候选与冲突依据。
4. 如需概率参考，打开“概率估计模式”后再次推理。
5. 调整或停用记录后重新推理，旧响应不会覆盖新对局状态。

### 技术实现与项目结构

- `web/`：原生 HTML/CSS/JavaScript 网页，负责向导、圆桌、记录编辑、协议请求与结果展示。
- `backend/`：Python 标准库 HTTP 服务，提供静态页面和 `/api/v1/reason`，并做运行时校验与错误区分。
- `connector.py`：网页 JSON 与推理模型之间的适配器，负责命题映射、查询和响应组装。
- `botc_reasoner/`：暗流涌动 Z3 模型，包括角色配置、变量与规则、输入分类、冲突诊断、候选世界及概率估计。
- `tests/`：后端、模型、前端及模拟对局测试。

接口采用无状态完整快照：每次请求携带整个对局，使用稳定的请求、对局、玩家和记录 id；逻辑上的 `unsat` 作为正常结论返回，不作为 HTTP 错误。
