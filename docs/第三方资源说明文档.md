# 第三方资源说明

本文记录项目实际使用的第三方资源、来源、许可证与用途。核查范围包括 `requirements.txt`、全部 Python/JavaScript import、网页静态资源、前端 CDN/字体/图片/图标，以及 README 中的规则外链。项目自研代码与 Python 标准库不计入第三方依赖。

## 运行依赖

| 资源 | 版本 | 来源 | 许可证 | 用途 |
| --- | --- | --- | --- | --- |
| z3-solver（含 libz3） | `requirements.txt` 要求 `>=4.13.0`；本机安装 `4.13.0.0` | PyPI 包，上游 [Z3Prover/z3](https://github.com/Z3Prover/z3) | MIT | 唯一运行期第三方库；`botc_reasoner/` 用它建立并求解暗流涌动规则的 SMT 约束 |
